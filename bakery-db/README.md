# Задание 3. Базы данных и отношения между таблицами

## Предметная область
Производственное планирование пекарни.

## Основные сущности
- **Ингредиент** (название, единица измерения, физический остаток)
- **Рецептура** (название, состав с количествами)
- **Производственная партия** (рецептура, количество, статус)
- **Заявка на выпечку** (пользователь, рецептура, количество, статус)
- **Пользователь** (имя)

## Реализованные бизнес-операции
1. Пополнение склада (увеличение остатка ингредиента).
2. Запуск производственной партии (списание ингредиентов).
3. Создание заявки на выпечку (с проверкой остатков).
4. Завершение партии (распределение готовой продукции по заявкам).
5. Отмена заявки.

## Технологии
- Java 21
- Spring Boot 4.1.1
- Spring Data JPA (Hibernate)
- PostgreSQL
- Maven

## Запуск
1. Настройте базу данных PostgreSQL (база `bakery_db`, пользователь `app_user`).
2. Пропишите данные в `.env` или `application.properties`.
3. Запустите `BakeryDbApplication`.
4. Используйте Postman или файл `requests.http` для проверки эндпоинтов.
